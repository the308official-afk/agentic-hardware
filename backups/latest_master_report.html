Experiment Setup And Manager Summary

This section is intended for slide-building: it shows the live request path, the hint/prefetch path, how the experiment was conducted, and the main evidence collected.

Simple Setup

part simple meaning example
1. Request source Real SWE-bench / DeepAgents tasks create model turns. SWE-bench task -> DeepAgents -> SGLang model request
2. Tool wait window The agent calls a tool, then pauses. That pause is the chance to prefetch KV. read_file(), grep(), or run_tests() is running
3. Resume request The tool returns, then the agent asks the model to continue. tests failed with error X; what should I do next?

Modes Compared

mode what happens
No prefetch The system waits until the resume turn arrives, then SGLang handles KV reuse/load normally.
Live prefetch During the tool wait, the hint path tries to prepare KV before the resume turn arrives.

What Was Measured

metric meaning
tool gap Time between a tool-call response and the next model request from the same live agent run.
prefetch duration How long the live software prefetch/controller path took to complete.
prefetch margin Whether prefetch finished before or after the real resume request boundary.
resume request latency End-to-end latency of the next model request after the tool gap.
late prefetch count How often the hint path missed the available tool-gap window.

What Was Observed

observation evidence
The traffic was live agent traffic, not synthetic prompts. 267 no-prefetch requests and 254 live-prefetch requests were analyzed.
The run produced real tool-call gaps. 127 no-prefetch gaps and 114 live-prefetch gaps were observed.
Tool gaps were often very short. Median live-prefetch tool gap was 9.477 ms.
Software prefetch was usually too slow for those windows. 112 late prefetch attempts; average prefetch duration was 629.527 ms.
Hints alone did not guarantee a win. Paired gaps=114; faster pairs=9; slower pairs=105.

Why This Supports The Hardware Proposal

Current GPU/runtime data-movement paths can move memory, but they do not know that a transfer is urgent KV for a soon-resuming agent session. This experiment shows that when prefetch is routed through ordinary software and SGLang request paths, it can miss short live tool gaps. A hint-aware hardware/runtime path could make these movements more predictable by prioritizing urgent KV, protecting prefetched KV, and exposing telemetry for late or wasted prefetches.

Key Deductions
finding evidence why_it_matters
This report uses real live SWE-bench / Deep Agents traffic. no-prefetch analyzed requests=267; live-prefetch analyzed requests=254. The request stream is no longer synthetic; tool calls, tool gaps, and resumes come from the real harness talking to SGLang.
Tool gaps are real prefetch opportunities. no-prefetch gaps=127; live-prefetch gaps=114; avg prefetch-run gap=19.877 ms. These gaps are where a runtime would issue KV residency hints after a tool call.
Best-effort software prefetch can miss short live windows. live-prefetch matched attempts=114; late attempts=112; avg prefetch duration=629.527 ms. If the controller/SGLang path takes longer than the tool gap, the next agent turn still arrives before the prefetch path finishes.
Prefetch can help or hurt depending on timing and interference. paired gaps=114; faster pairs=9; slower pairs=105; avg gain=-130.359 ms. This supports the hardware story: policy hints alone are not enough; movement needs deadline-aware scheduling, protection, and telemetry.
Live pairing is useful, but not perfectly deterministic. Pairs are matched by SWE-bench task index plus gap order inside that task. The two live agent runs can choose slightly different actions, so exact per-gap comparisons should be read alongside aggregate trends.
